About this map

How to use
Stamp a province by tapping it on the map, or by tapping its row in the list. Tap it again to take the stamp off. Stamped provinces turn green on the map and show a tick in the list. The count, the percentage and the island bars all follow along.
Move the map by dragging to pan, and scrolling or pinching to zoom. The + and − buttons zoom as well, and FIT returns to the whole archipelago.
Name your log with a nickname in the field under the counter. Put in Abi’s and the log is titled Abi’s PH travel log — on the page, in the browser tab, and as the heading on the saved image. The nickname travels inside the saved file too. It is kept in this browser like everything else. Leave it empty and the page goes back to being called Eighty‑Two.
Work the list by typing part of a name in Find a province to narrow it, and switching between Island and Region to group it by island group or by administrative region.
Keep a copy with the buttons at the top. Save file writes your log out as a JSON file and Load file reads one back in. Save image draws your map as a PNG to keep or post. Clear empties the log. Loading a file replaces whatever is currently stamped in this browser, so save a copy first if you want to keep it. The saved file is also how you carry your log to another device.
Where your log is kept
In this browser, on this device. Nothing is uploaded and there is no account. Clearing your browser data will erase it. Use Save file to keep a copy and to carry your map to another device.
The count of 82
This map follows the 2023 Philippine Standard Geographic Code list of provinces, which is where the figure of 82 comes from. The number is not settled. Maguindanao was split into two provinces in 2022, and other splits and mergers are proposed regularly. Metro Manila is not a province and is not counted here.
